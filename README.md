# cat-charity-2
Добро пожаловать в благотворительный фонд поддержки котиков QRKot!
В данном проекте можно взаимодействовать с 2 типами объектов: пожертвование и сбор. При создании нового пожертвования, его сумма распределяется по проектом от старых к новым, пока не закончатся деньги. Если же все проекты закрыты, в объекте пожертвования остается остаток, который будет уменьшен или истрачен при добавлении нового проекта.


Права доступа:
В проекте рписаны 3 типа ролей: неавторизованный пользователь(Н), обычный (авторизованный) пользователь(А) и супер-пользователь(С).

Н-пользователь может зарегистрироваться и просмотреть список всех проектов для пожертвований.

А-пользователь может делать все то же, что и Н-пользователь, а также добавлять новые донаты, получить список своих пожертвований.

С-пользователь может делать все, что доступно в пределах эндпоинтов и логики приложения.


Для развертывания проекта на локальном компьютере:
1) клонируйте проект: **git clone https://github.com/NoRazoom/cat-charity-1.git**

2) разверните виртуальное окружение: **python -m venv venv**

3) Активируйте виртуальное окружение: **. venv/Scripts/activate**

4) Импортируйте зависимоти: **pip install -r requirements.txt**

Рекомендуется использовать версию Python 3.11 или 3.12!

Запустить проект на локал-хосте можно командой **uvicorn app.main:app**


С полной документацией можно ознакомиться по адресу: _http://127.0.0.1:8000/docs#/_


Использованные технологии: FastAPI, pydantic, alembic, fastapi-users
